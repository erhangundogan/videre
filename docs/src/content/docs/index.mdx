## Why videre

Most photo tools want to *own* your library. They import everything into their
own storage, index it somewhere only they can read, then nudge you toward their
cloud. videre is a lens over a folder you already own: point it at a directory
and you get one SQLite file describing what is there. Stop using it and your
photos are exactly as they were.

**Nothing leaves your machine.** No account, no upload, no telemetry, no
background sync. Search, faces and classification all run locally. The single
exception is [`search --location`](/commands/search/), which resolves a place
name once and caches it.

**Built for volume.** Routinely run against libraries of 70,000 files and
400 GB. Face detection parallelises across your cores, the long jobs are
resumable, and filtering happens before ranking so a narrow query does *less*
work, not more.

**One binary, no runtime.** `brew install`, or download and run. Written in
Rust, so there is no interpreter, no virtualenv, no container, and nothing to
keep running in the background.

**Your data stays legible.** Plain SQLite you can open with any tool and query
yourself. No proprietary format, no daemon holding it open. The
[schema is documented](/reference/database/), including example queries.

**The unglamorous work, done properly.** Duplicate detection by content hash and
by appearance, EXIF date repair, orphan cleanup, and browsable HTML reports.
This is most of what a photo archive actually needs.

**AI search that runs on your own hardware.** Find images by describing them, by
example, by who is in them, by category, or by place, and
[combine those in one query](/guides/compositional-search/) with a date range.

**Swap the model.** The default is one line of config away from a larger one,
and [each keeps its own data](/reference/models/), so you can compare them on
your own library and switch back freely.

**Drive it from an agent.** [`videre mcp`](/commands/mcp/) exposes search,
duplicate review and stats over stdio, read-only, with no server to run.

**Documented, not just shipped.** Every command and flag, with the caveats and
the measured numbers behind the defaults.
